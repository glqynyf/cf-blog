# 关于

**盘面札记**是我写给自己的投资笔记站——**115 篇笔记、14 个章节**，从「为什么会亏钱」一路排到「市场周期与情绪」。

所有内容都是**个人复盘与学习笔记**，不构成任何投资建议。市场的不可知性远比任何指标都大。

## 适合谁看

- 刚开始接触 A 股、想把常见技术指标和交易规则一次性理清的散户。
- 已经入市几年、想梳理自己交易体系（选股 → 仓位 → 止损）而不是零散记笔记的人。
- 对财报识别、估值方法、资金面与市场周期感兴趣的同好。
- 想找**可证伪**结论的人——这里给结论一定同时给条件。

## 不适合谁看

- 寻找"必胜指标"或"一夜翻倍秘籍"的人——这里没有这种东西。
- 想把别人策略直接照搬的人——任何策略都需要适配自己的风险偏好与资金量级。
- 期待荐股的人——这里只讲方法与推理过程，不给标的。

## 写作原则

1. **诚实**——亏损的票、犯过的错也会写出来，不刻意制造"股神"人设。
2. **可证伪**——给结论必给条件，条件不成立时主动修订，而不是换个说法圆回来。
3. **节制**——宁可少写也不灌水，每一篇尽量给出一个能立刻用上的认知。
4. **区分事实与观点**——引用数据给出来源，讲判断时明说那是判断。
